# Attendance-management-system

## About the Project
The Student Attendance Management System is a web-based application designed to simplify student attendance recording and management.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Main Features
- Student registration and management
- Student dashboard
- Attendance recording
- Automatic attendance percentage calculation
- Course and subject management
- Lecturer management
- Student profiles
- Attendance reports

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your web browser.
